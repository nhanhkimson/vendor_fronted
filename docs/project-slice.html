Multi-vendor marketplace

What it is

Three surfaces, one platform

Buyers, sellers, and staff each get their own place — all talk to the same API.

1

Website

Browse shops & products, cart, checkout, track orders.

2

Seller

Manage catalogue, stock, ship orders, ask for payouts.

3

Admin

Verify shops, publish products, disputes, payouts.

Who uses it

Four jobs, one login

Each role has one main job. Staff share the Admin console.

Customer

Buy and track. Home: /account

Vendor

Run a shop. Home: /seller

Staff

Check shops & listings. Home: /admin

Owner

Roles & control. Home: /admin

Control

Maker-checker: two people

The person who submits cannot be the only one who approves.

1

Shop

Vendor submits → staff verify → shop goes live.

2

Product

Vendor sends for review → staff publish or reject.

3

Payout

Vendor requests → two different staff must sign.

Navigation

Login cards open the right door

Same login page. Role decides where you land.

  • Customer → /account
  • Vendor → /seller
  • Staff / Owner → /admin
  • Demo password for every seed account: demo

Tech (simple)

Next.js → Flask → Postgres

Browser only talks to Next.js. API and media are proxied.

  • Next.js — website + dashboards
  • Flask API — REST + docs at /api/docs
  • PostgreSQL + RLS — each shop only sees its own data
  • Money in integer cents — no float mistakes
