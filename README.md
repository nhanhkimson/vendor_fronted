# Bazaar Platform

A multi-vendor marketplace (Topic 01) built as a real full-stack project:

- `backend/` FastAPI + PostgreSQL API with Swagger UI at `/api/docs`
- `frontend/` Next.js storefront, Seller Central and Admin Console that read everything from the API
- `docs/` system analysis: architecture, use cases, ER diagram, state machines, API map, permission matrix, test evidence

Setup, credentials and the demo script are added as the project is built.
